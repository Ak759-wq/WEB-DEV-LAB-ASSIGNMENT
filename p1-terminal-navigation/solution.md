
# P1: Project Folder and Terminal Navigation

## Aim
To create a project folder, navigate through directories, and perform basic file operations using Terminal.

## Commands Used

### 1. Create a project folder
mkdir MyPortfolio

### 2. Navigate into the folder
cd MyPortfolio

### 3. Display current directory
pwd

### 4. Create a subfolder
mkdir images

### 5. Create files
touch index.html style.css script.js

### 6. List files and folders
ls

### 7. Move to parent directory
cd ..

### 8. Enter the project folder again
cd MyPortfolio

## Expected Folder Structure

MyPortfolio/
├── images/
├── index.html
├── style.css
└── script.js

## Command Explanation

- mkdir: Creates a directory.
- cd: Changes the current directory.
- pwd: Displays the current directory path.
- ls: Lists files and folders.
- touch: Creates an empty file.
- cd ..: Moves to the parent directory.

## Result
Successfully created a project folder and performed basic terminal navigation and file operations.
